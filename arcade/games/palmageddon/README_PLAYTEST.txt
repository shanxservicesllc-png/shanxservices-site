PALMAGEDDON V8 | PUBLIC PLAYTEST PACKAGE | 2026-10-29
Original playable browser game by ShanX Services LLC.
Four 3D venues, five original human fighter exports, timed one-turn slap combat,
portrait and landscape rotation support, original synthetic game music.

How to deploy: upload or extract these files as a static website, retaining
the index.html, game.js, audio_v7.js, assets/ and vendor/ layout.
Requires HTTPS or localhost and a WebGL 2-capable browser.
This package intentionally excludes MONSTER source scripts, backups, tests,
browser QA screenshots, personal folders and unnecessary npm modules.
No network APIs, authentication, personal data collection, remote analytics or
persistent gameplay storage are included. Feedback collection requires a
separate explicitly selected contact form or public discussion destination.

Game source/assets: owner ShanX Services LLC.
Generated adult characters: MakeHuman-based 3d-gen pipeline (asset data per
upstream attribution/license; review before commercial release).
Engine: PlayCanvas, license included under vendor/LICENSE-playcanvas.txt.
Music and effects: original procedural audio generated in browser.

PUBLIC PLAYTEST IS NOT THE OFFICIAL JAM SUBMISSION.
The final HTML5 game must be directly uploaded playable to itch.io under
the applicable jam rules. Owner acceptance still required.
